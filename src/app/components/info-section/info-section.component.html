我的世界模组更新器

此工具可以帮助你通过 Modrinth API（在新标签页打开） 查找更新并迁移你的 Minecraft Java 模组，只需将它们作为 .jar 文件上传即可

使用教程:

  1. 选择你的模组加载器（Fabric / Forge / Quilt / NeoForge）
  2. 选择你的目标 Minecraft 版本
  3. 上传你的模组或直接拖放到此页面上
  4. 工具将自动查找目标版本的模组供你下载

你也可以上传资源包（.zip）、光影（.zip）和整合包（.mrpack）， 并且支持降级到特定版本
模组包开发者同样可以使用这个工具，只需上传 modrinth.index.json 文件， 工具将自动更新模组包中的模组到最新版本
